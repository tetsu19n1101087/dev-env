# 文字・余白・角丸

## フォント

- 日本語と英数字で分けることが多い（entre-web: 日本語 Noto Sans JP、英数字 Inter）。CSS では英字フォントを先に書き、日本語は後ろのフォントで表示させる（`Inter, "Noto Sans JP", sans-serif`）
- Figma のテキストスタイルはフォントを1つしか持てない。日本語の方（`font-family/ja`）を設定する。tokens.json の `styleFontFamily` で指定する
- 太さは使うものだけ（400 / 700 など）。読み込む太さが減り、`font-medium` のような中途半端な太さが紛れ込まない
- Next.js なら `next/font/google` で読み込む

## サイズの段階

Figma のバリアブル `font-size/*` に数値で番号を付ける（`50`=12px、`75`=14px、`100`=16px、`200`=20px、`300`=28px）。番号を飛ばしておくと、後から間に足せる。

既存コードがある場合は、使われているサイズを洗い出し、段階にないもの（例: 18px、24px、30px）をどこに寄せるかを「実装との差分」に書く。

## 行の高さ

**単位なしの倍率で、文字サイズ × 倍率が4の倍数になる値**にする。倍率は文字サイズごとに1つで、系統（heading / body / label）をまたいで共通。

| 文字サイズ | 倍率 | 高さ |
| --- | --- | --- |
| 12px | 1.67 | 20px |
| 14px | 1.71 | 24px |
| 16px | 1.75 | 28px |
| 20px | 1.6 | 32px |
| 28px | 1.57 | 44px |

倍率は小数第2位までなので実際は 20.04px のようにずれるが、4の倍数として扱う（build.mjs は ±0.1px を許容する）。

1行で使う部品（バッジ、ボタン）は倍率 1 にしてよい。高さはパディングと最小の高さで決める。複数行になる文章には使わない。

Figma のテキストスタイルには同じ倍率を % で設定する（167% など）。**行の高さのバリアブルは作らない**。Figma の行の高さのバリアブルは px でしか紐づかず、倍率を表せない。

## 字間

Figma ではテキストスタイルに **% で直接**設定し、コードでは同じ値を **em** で書く（10% = 0.1em）。**バリアブルは作らない**（行の高さと同じ理由。px で紐づくと文字サイズごとに値が変わる）。

決め方の例（entre-web）: 見出しとナビだけ広げ、ほかは 0。

- heading/xl・lg・md: 4%
- heading/md-wide（トップページのセクション見出し）: 10%
- label/md（ナビ）: 2%
- body・バッジ・ボタン: 0%

**同じサイズでも用途で字間を変えたいときは、値を上書きせずに別スタイル（`-wide`）を作る。** entre-web では最初 heading を一律 10% にしたが、トップページのセクション見出しには合う一方、記事の中の見出しには広すぎた。heading の既定を 4% に下げ、トップページ用に `heading/md-wide` を分けた。コードで `tracking-*` を個別に足すと、Figma との対応が崩れる。

日本語の本文は 0〜5% 程度が多い。英字フォント（Inter など）は大きいサイズほど詰めるのが基本なので、見出しを広げるときは英数字の見え方も確認する。

## テキストスタイルの系統と名前

`<系統>/<段階>`。段階は `xl lg md sm xs` で、**md を標準**にする。

- heading: 見出し
- body: 本文（`<body>` に body/md を指定し、クラスなしの文字は body/md）
- label: UI の見出しラベル、ナビ、バッジ
- button: ボタン（ボタンのサイズ名に合わせて sm / lg の2段階でもよい）

**用途が衝突したら系統を分ける。** entre-web では、ボタンのラベルを label に相乗りさせていたが、ボタンのサイズ要件（12px / 20px）とバッジ・見出しラベルの要件が衝突したので button 系統を作った。

tokens.json の各スタイル:

```json
"heading/xl": { "size": "300", "weight": "bold", "lineHeight": 1.57, "letterSpacing": 10, "use": "ページ見出し（h1）", "sample": "起業家教育の事例 128" }
```

`sample` は一覧ページの見本の文字。案件の実際の文言にすると判断しやすい。

### コード（Tailwind v4）

`@theme` に `--text-*` として定義すると、1クラスでサイズ・行の高さ・太さ・字間がそろう。標準の `text-xs`〜`text-3xl` は `--text-*: initial` で無効化し、テキストスタイル以外を使えないようにする。

```css
@theme {
  --text-*: initial;
  --text-heading-lg: 1.25rem;
  --text-heading-lg--line-height: 1.6;
  --text-heading-lg--font-weight: 700;
  --text-heading-lg--letter-spacing: 0.1em;
}
```

入力欄は iOS Safari のフォーカス時ズームを防ぐため、`md` 未満は 16px（body/md）にする。

## 余白

4 / 8 / 16 / 24 / 32 / 48 / 64 / 80px のような段階にし、Figma のバリアブル `space/*` を作る。中途半端な値（12px など）は段階に入れないと決めたら、既存コードの該当箇所を「実装との差分」に積む。部品の要件で中途半端な値が欲しくなったら（例: ボタンの左右 12px）、段階に寄せるか段階を足すかをその場で決める（entre-web は 16px に寄せた）。

## 角丸

種類を絞る（entre-web: 8px と半円の2種類）。ボタンを半円（9999px）にするなら、アイコンだけのボタンは円になる。Figma のバリアブル `border/radius` は余白の段階を参照させてもよい。
